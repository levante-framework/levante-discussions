# levante-discussions
A discussion forum repo for the LEVANTE project.

To receive email notifications about activity on our [Discussion Board](https://github.com/orgs/levante-framework/discussions), click "Watch" above (on this page) and select the type(s) of activity you'd like to be notified about. 

Visit your [GitHub settings](https://github.com/settings/notifications) to set your email notification preferences for repositories you are watching.
